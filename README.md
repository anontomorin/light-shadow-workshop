# 光影工坊：影子设计师

一款以**三维空间关系**和**投影变化**为核心机制的浏览器益智游戏。玩家在明亮的光影工作室里移动、旋转几何物体并调整光源位置，让墙上的影子与目标轮廓重合。

- **技术栈**：Vite + TypeScript + Three.js（渲染）+ Canvas 2D（掩码计算）
- **运行形态**：纯前端，无后端、无账号、无数据库
- **核心机制**：真实几何投影计算 + 像素掩码 IoU 轮廓匹配（非预设动画、非进度条伪造）
- **在线试玩**：<https://anontomorin.github.io/light-shadow-workshop/>

## 二、操作方法

桌面端以鼠标为主，键盘为辅。

| 操作 | 行为 |
|---|---|
| 左键点击物体 | 选中物体，显示高亮描边 |
| 按住左键拖动 | 在操作平面内移动选中物体，影子实时跟随 |
| `Q` / `E` | 选中物体逆时针 / 顺时针旋转 5°（按住 `Shift` 为 15°） |
| 方向键 | 微调选中物体位置（0.04 世界单位；按住 `Shift` 为 0.18） |
| 右侧面板滑杆 | 调整选中物体的**面内角度**、**翻转**与**深度**（离墙距离） |
| 光源控制滑杆 | 调整光源**水平位置**、**高度**、**距离**（改变整体投影比例） |
| **右键拖动** | **环绕观察**（改变水平角与俯仰角） |
| `Shift` + 右键 / 中键拖动 | 平移观察中心 |
| 滚轮 | 缩放视角（改变相机距离） |
| 「观看视角」面板 | 两个角度滑杆 + 距离滑杆 + 5 个预设视角 + 一键复位 |
| `R` | 重置当前关卡（自由实验室中为重置场景） |
| `H` | 显示一条提示 |
| `Esc` | 暂停 / 关闭弹窗（自由实验室中为返回标题页） |

**观看视角**在合理范围内可自由改变：水平角 `[-62°, 80°]`、俯仰角 `[8°, 70°]`、距离 `[13, 40]`。
这些约束保证相机始终位于投影墙**前方**且高于地面，玩家不会转到看不到影子、或只能看到墙背面的位置。
预设视角提供「三分之四 / 正视 / 俯视 / 左侧 / 右侧」五种常用机位，`复位视角` 一键回到默认三分之四机位。
切换视角**不会**影响投影计算与匹配判定：投影始终以墙面世界坐标为基准，视角只改变观察方式。

**通关规则（严格）**：墙上影子的轮廓匹配度（IoU）达到本关阈值，且**连续 3 次校验**均达标才通关——
这意味着玩家必须把影子稳定地放在正确位置，而不是拖动中擦过阈值。粗略摆放（约 ±0.12 世界单位）
**不足以通关**，必须精修到约 ±0.09 以内。拖动过程中不判负、不计时，操作次数只影响结算评价
（完成 / 优秀 / 大师）。

## 三、技术说明

### 3.1 几何投影公式

采用**点光源 + 平面投影**的简化几何模型。坐标约定：`X` 为墙面水平方向，`Y` 为垂直方向，
`Z` 为深度方向，投影墙位于 `Z = 0`，光源位于正 `Z` 端且比所有物体更靠近观察者。

设点光源 `L = (Lx, Ly, Lz)`，物体顶点 `P = (Px, Py, Pz)`，墙平面 `z = Zw`，则光源过顶点的射线与墙面交点 `Q`：

```text
t  = (Lz - Zw) / (Lz - Pz)
Qx = Lx + t * (Px - Lx)
Qy = Ly + t * (Py - Ly)
```

实现要点（`src/projection/Projector.ts`）：

- **顶点变换**：读取几何体局部顶点，用 `Matrix4.compose(position, quaternion, scale)` 得到世界坐标；
- **异常保护**：当 `|Lz − Pz| < 1e-4`（顶点逼近光源）时返回 `null` 并丢弃该顶点；全局还有深度安全余量
  `MIN_LIGHT_GAP = 2.0`，物体与光源的深度差不会小于该值。
- **轮廓取凸包**：所有基础形状都是凸多边形，且物体有薄厚度（前后两层顶点）。
  对投影点集求 **Andrew monotone chain 凸包**，一步完成「外轮廓提取」与「前后两层合并」。
- **墙面裁剪**：用 **Sutherland–Hodgman** 算法把投影多边形裁到墙面矩形内，超界部分丢弃。

> 这是针对指定几何体的投影计算，**不是**完整的真实光学仿真，不涉及波长、干涉、衍射等现象。

### 3.2 轮廓匹配算法

`src/projection/SilhouetteRasterizer.ts` + `SilhouetteMatcher.ts`：

1. 墙面取 `18 × 10` 世界单位的标准区域，映射到 `288 × 160` 的离屏 Canvas。
   `18/288 = 10/160 = 0.0625`，即**每个像素恰好对应各向同性的世界尺度**，IoU 不受方向影响。
2. 当前影子与目标轮廓使用**同一套 `wallToMask` 坐标映射**，保证显示与判定一致。
3. 多边形以纯色填充到离屏 Canvas，读取像素后按 Alpha 阈值二值化为掩码。
4. 计算交并比：

```text
IoU = 交集像素数 / 并集像素数
```

- **节流**：拖动过程中使用降采样低分辨率预览（只在参数变化时重算），松手后再做完整校验，避免每帧读像素。
- **目标轮廓固定**：目标掩码在关卡加载时由「目标变换参数」一次性生成，**不随玩家移动光源而跟随变化**。
- **防误判**：判定基于整个目标区域的掩码而非局部重合，且要求连续两次达标才通关。

### 3.3 交互与视角实现

- **拾取**：`THREE.Raycaster` 对物体做射线相交；
- **拖动**：把鼠标射线与通过物体当前位置的**操作平面**求交，增量位移施加到物体上，避免屏幕上的突然跳跃；
- **边界限制**：物体与光源都被限制在 `OBJECT_LIMITS` / `LIGHT_LIMITS` 合法区域内，非法值经 `clampSafe` 回退；
- **拖拽期间**的匹配度更新做了节流，松手后做完整校验；
- **相机**（`src/scene/SceneManager.ts`）：以默认机位反算出球坐标作为基准
  （水平角 42.3°、俯仰角 11.2°、距离 22.7），相机位置由
  `pos = target + d · (cos(el)sin(az), sin(el), cos(el)cos(az))` 求出。
  视角状态经 `clampView` 夹紧到 `VIEW_LIMITS`；右键拖动改角度、中键/`Shift`+右键平移、滚轮改距离，
  平移量限制在 `±6 / ±3.5 / ±6`，避免把观察中心推离场景。
- **同一套渲染资源**被关卡界面与自由实验室复用：`SceneManager.mount(container)` 把画布搬到
  当前界面的舞台容器并重新监听尺寸变化，因此两个界面共享同一个 `WebGLRenderer`，不会重复创建上下文。

### 3.4 自由实验室

自由实验室是一个**不设目标、不评分**的沙盒（`src/gameplay/LabSession.ts` + `src/ui/LabHUD.ts`）：

- 默认摆出方块 / 圆盘 / 三角各一个；最多可容纳 10 个物体（超出时添加按钮自动禁用）；
- 可添加 6 种形状（正方形 / 圆形 / 三角形 / 长方形 / 六边形 / 菱形），可删除选中物体，可一键重置场景；
- 选中后即可拖动、旋转、翻转、调整深度，全部复用与正式关卡相同的交互链路
  （`InteractionController`，`LAB_CONTROLS` 打开全部维度）；
- 墙面影子由 `LabSession.polygons()` 用**与关卡完全相同的投影与裁剪函数**计算，因此观察到的
  影子变化规则与正式关卡一致；
- 光源三轴滑杆与「观看视角」面板完全可用；
- 从标题页或关卡选择页均可进入，`Esc` 或「返回标题页」退出。

## 四、关卡设计

6 个关卡均通过 `src/data/levels.ts` 配置，配置项包含每关的初始/目标光源、各物体的初始/目标变换、
通关阈值与高评价阈值、分阶段提示、建议操作次数。

| 关卡 | 名称 | 物体 | 教学目标 |
|---|---|---|---|
| 1 | 光的初遇 | 1 个方块 | 选中、拖动，观察影子跟随 |
| 2 | 角度的秘密 | 1 个三角形 | 旋转物体，理解姿态对投影的影响 |
| 3 | 远近之间 | 1 个圆/方 | 调整光源距离与物体深度，观察投影缩放 |
| 4 | 组合的艺术 | 长方 + 圆/三角 | 多物体组合出**树形**轮廓 |
| 5 | 飞鸟的轮廓 | 菱形主体 + 2 翅膀 | 组合出抽象**飞鸟**形状 |
| 6 | 光影之城 | 4—6 个基础形状 | 组合成**城市天际线**（综合关） |

**通关阈值（已收紧）**：阈值不是拍脑袋定的，而是用 `npm run verify` 的两档扰动实测校准——
**粗对齐**（±0.12 世界单位 / ±5°）必须**低于**通关阈值（粗略摆放不再能过关），
**精对齐**（±0.05 / ±2°）必须**达到**大师阈值（认真微调一定能过关）。

| 关卡 | 通关 | 优秀 | 大师 | 建议操作 | 粗对齐实测 | 精对齐实测 | 离散控件可达 |
|---|---|---|---|---|---|---|---|
| 1 光的初遇 | 0.80 | 0.84 | 0.86 | 14 | 0.731 | 0.870 | 0.999 |
| 2 角度的秘密 | 0.79 | 0.83 | 0.85 | 22 | 0.713 | 0.866 | 0.960 |
| 3 远近之间 | 0.81 | 0.85 | 0.87 | 26 | 0.749 | 0.888 | 0.965 |
| 4 组合的艺术 | 0.83 | 0.87 | 0.89 | 44 | 0.775 | 0.906 | 0.994 |
| 5 飞鸟的轮廓 | 0.80 | 0.84 | 0.86 | 46 | 0.727 | 0.871 | 0.931 |
| 6 光影之城 | 0.83 | 0.87 | 0.88 | 68 | 0.776 | 0.892 | 0.978 |

**关卡可解性验证**：`npm run verify` 会为每关

1. 用目标变换参数生成目标掩码，做 CPU 端 ASCII 预览（可直接肉眼检查图案是否可辨认）；
2. 将状态置为目标参数，计算与目标掩码的 IoU，必须 ≈ 1.0；
3. 对目标参数施加「粗对齐 / 精对齐」两档扰动，并断言
   `粗对齐 < 通关阈值 ≤ 精对齐`、`精对齐 ≥ 大师阈值`；
4. **离散控件可达性**：把目标吸附到玩家实际能摁出的最小粒度
   （位置 0.04、深度 0.1、角度 1°、旋转 5°、光源 0.1），所得 IoU 必须仍 ≥ 通关阈值，
   证明严格阈值是"够得着"的（实测 0.93–0.999，远高于阈值）；
5. 恢复初始状态，确认与目标存在明显差异；
6. 校验深度合法性与目标是否贴边。

6 关目标状态实测 IoU **全部为 1.0000**。

## 六、已知限制与未实现功能

已实现：6 个完整关卡、关卡选择与解锁、提示系统、三档评价、本地存档、
选中/拖动/旋转/深度/光源控制、**可改变的观看视角（滑杆 + 预设 + 右键环绕）**、
**自由实验室**、暂停与重置、通关演出、轻量音效（可静音）。

已知限制：

- 投影为**几何投影模型**，非真实光学仿真；不模拟焦距、半影、折射等。
- 观看视角被约束在投影墙前方的合理范围（水平角 `[-62°, 80°]`、俯仰角 `[8°, 70°]`、
  距离 `[13, 40]`），不能转到墙背面——这是刻意设计，避免玩家看到镜像的影子而无法理解投影关系。
- 物体投影统一取**凸包**：对当前所有关卡与实验室的基础凸形状完全正确；若未来引入凹多边形，
  需要改为按边投影或并集处理。
- 通关阈值较严格（0.79–0.83 且需连续 3 次达标），对首次接触的玩家可能需要多试几次；
  界面上的匹配度进度条与方向键微调是达成精度的主要手段。
- 仅在桌面端近年版本 Chrome 实测通过；Firefox / Safari / Edge 建议实机复测。
- 窄窗口（< 1024 px）下 HUD 会压缩，未做移动端专门适配。

未实现（原文档中列为 P1 / P2 或可选）：

- 音效之外的可选音效素材与无障碍设置、自定义影子创作与截图导出、XR / AR 模式均未实现。
